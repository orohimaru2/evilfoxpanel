# EvilFox Panel

Макет VPN-панели. По составу экранов ориентир — привычная админка вроде Marzban: статистика, пользователи, хосты, группы, шаблоны, ноды, админы, настройки. Это отдельный интерфейс EvilFox, без ядра и без API.

Демо-данные зашиты в страницу. Кнопки сохранения ничего не записывают.

## Локально

```bash
docker compose up --build
```

Панель открывается на [https://localhost:10000](https://localhost:10000). Это единственный рабочий порт: Caddy принимает HTTPS и передаёт запрос во внутренний nginx. Порт 80 наружу не публикуется.

Сертификат выпускает внутренний центр Caddy, поэтому браузер один раз предупредит о подписи. Корень можно забрать так:

```bash
docker compose cp caddy:/data/caddy/pki/authorities/local/root.crt ./caddy-root.crt
```

На экране входа любые имя и пароль просто открывают оболочку.

## Dokploy

1. Создайте сервис типа Compose и укажите `docker-compose.dokploy.yml`.
2. Запустите деплой и откройте `https://<сервер>:10000`.
3. В файрволе разрешите входящий TCP 10000.

Домен во вкладке Domains для этой панели не нужен: TLS уже завершает Caddy. Имя контейнера не задано специально, так Dokploy собирает логи и метрики.
