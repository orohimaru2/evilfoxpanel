# EvilFox Panel

Макет VPN-панели. По составу экранов ориентир — привычная админка вроде Marzban: статистика, пользователи, хосты, группы, шаблоны, ноды, админы, настройки. Это отдельный интерфейс EvilFox, без ядра и без API.

Демо-данные зашиты в страницу. Кнопки сохранения ничего не записывают.

Подробные шаги для сервера: [развёртывание на Ubuntu](docs/ubuntu.md).

## Локально

```bash
docker compose up --build
```

Без файла `.env` панель открывается на [https://localhost:10000](https://localhost:10000) с внутренним сертификатом. Браузер покажет предупреждение: это не Let's Encrypt.

Настоящий сертификат выпускается на сервере с доменом. Порядок такой: запись DNS, открытые порты 80 и 10000, файл `.env` с `TLS_MODE=letsencrypt`. Полные команды — в [инструкции для Ubuntu](docs/ubuntu.md). Панель после этого доступна как `https://домен:10000`. Порт 80 нужен только проверке Let's Encrypt.

На экране входа любые имя и пароль просто открывают оболочку.

## Dokploy

1. В переменных окружения задайте `TLS_MODE=letsencrypt`, `PANEL_DOMAIN` и `ACME_EMAIL`.
2. Создайте сервис типа Compose и укажите `docker-compose.dokploy.yml`.
3. Убедитесь, что порт 80 свободен: его должен занять Caddy, а не Traefik.
4. Откройте в файрволе TCP 80 и TCP 10000.

Домен во вкладке Domains не добавляйте. Traefik ходит в контейнер по HTTP и ломает TLS, который уже завершает Caddy. Если Dokploy уже держит порт 80, выпустите сертификат на отдельном сервере по инструкции для Ubuntu.
