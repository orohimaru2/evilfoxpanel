# EvilFox Panel

Макет VPN-панели. По составу экранов ориентир — привычная админка вроде Marzban: статистика, пользователи, хосты, группы, шаблоны, ноды, админы, настройки. Это отдельный интерфейс EvilFox, без ядра и без API.

Демо-данные зашиты в страницу. Кнопки сохранения ничего не записывают.

## Локально

```bash
docker compose up --build
```

Панель откроется на [http://localhost:8080](http://localhost:8080). Порт меняется через `PANEL_PORT` в `.env`.

На экране входа любые имя и пароль просто открывают оболочку.

## Dokploy

1. Создайте сервис типа Compose и укажите `docker-compose.dokploy.yml`.
2. Во вкладке Domains выберите сервис `panel` и порт контейнера `80`.
3. Запустите деплой.

Файл уже подключает внешнюю сеть `dokploy-network`, чтобы Traefik Dokploy мог достучаться до контейнера. Имя контейнера не задано специально: так Dokploy собирает логи и метрики.
